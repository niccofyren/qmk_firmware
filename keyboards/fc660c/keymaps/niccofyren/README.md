# The niccofyren keymap for the FC660C


Main changes (to align with macOS keyboard layouts)
- Used KC_BSLS as backspace by default, and KC_BSLS via FN
- Switches the left Alt and command keys

Possible changes
- Add a key for the `~` character, which is commonly used on macOS. This could be done by assigning it to a key that is not frequently used, such as the right Alt key (KC_RALT).
